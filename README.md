# CoolCare – AC Service Booking App UI

## Project Overview

CoolCare is a mobile-first appointment booking application designed for AC repair and maintenance services. The app simplifies the process of booking technicians for AC installation, repair, gas refilling, and annual maintenance through an intuitive and user-friendly interface.

## Objectives

- Design a seamless appointment booking experience
- Simplify service selection and scheduling
- Improve user convenience through a mobile-first approach
- Create an intuitive and efficient booking workflow

## Features

- User Onboarding
- Login / Sign Up
- Service Selection
- Technician Selection
- Date Selection
- Time Slot Booking
- Booking Summary
- Appointment Confirmation

## User Flow

Onboarding → Login → Select Service → Choose Technician → Select Date → Choose Time Slot → Booking Summary → Confirmation

## Screens Designed

### 1. Onboarding Screen
Introduces the application and its services.

### 2. Login / Sign Up Screen
Allows users to access their accounts.

### 3. Service Selection Screen
Users can choose from:
- AC Repair
- AC Installation
- Gas Refilling
- Annual Maintenance

### 4. Technician Selection Screen
Displays available technicians with ratings and experience.

### 5. Date Selection Screen
Users select their preferred service date.

### 6. Time Slot Selection Screen
Users choose an available appointment slot.

### 7. Booking Summary Screen
Displays complete booking details before confirmation.

### 8. Confirmation Screen
Shows successful booking confirmation and appointment details.

## UX Considerations

- Clean and minimal interface
- Easy navigation between screens
- Reduced booking steps
- Clear call-to-action buttons
- Mobile-friendly design
- Consistent visual hierarchy
